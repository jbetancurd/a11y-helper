## Detailed Description
```
Accessibility Helper makes the web more accessible for everyone, especially people with disabilities.

🎯 WHO IS THIS FOR?
• People with visual impairments (low vision, colorblindness)
• People with motor disabilities (difficulty using a mouse)
• People with cognitive disabilities
• Elderly users who need larger text
• Anyone who struggles with poorly designed websites

✨ KEY FEATURES

📏 Adjustable Text Size
Increase or decrease text size from 50% to 200% on any website. Perfect for people with low vision or anyone who finds text too small.

🎨 High Contrast Mode
Enhance color contrast for better readability. Helps people with low vision or colorblindness.

⌨️ Keyboard Navigation
Enhanced focus indicators make it easy to navigate websites using only your keyboard. Essential for people who can't use a mouse.

🔊 Read Aloud
Text-to-speech feature reads page content aloud. Helpful for people with visual impairments or reading difficulties.

🔍 Accessibility Scoring
Automatically detects accessibility issues on websites and shows you what's wrong.

🔧 Auto-Fix
One-click fixes for common accessibility problems like missing image descriptions and form labels.

💡 Helpful Tips
Get contextual suggestions for improving accessibility on each page you visit.

🎛️ Floating Control Panel
Always-accessible panel that stays on screen. Drag it anywhere you want. Use Alt+A to show/hide.

⚙️ Customizable Settings
Save your preferences and they'll apply to all websites automatically.

🔐 PRIVACY & SECURITY

✅ All processing happens locally in your browser
✅ No data collection or tracking
✅ No external servers or API calls
✅ No ads or premium features
✅ Completely free forever
✅ Open source - you can review the code

♿ ACCESSIBILITY

This extension itself is built to WCAG AAA standards:
• High contrast design (7:1 ratio)
• Large touch targets (44×44 pixels)
• Full keyboard navigation
• Screen reader compatible
• Respects user preferences (reduced motion, dark mode)

🆓 FREE & OPEN SOURCE

No hidden costs, no premium features, no ads. This extension is completely free and always will be. The source code is available for anyone to review.

📱 HOW TO USE

1. Install the extension
2. Visit any website
3. Look for the floating panel in the corner
4. Click to expand and use the controls
5. Press Alt+A to quickly show/hide the panel

🌟 PERFECT FOR

• Reading news websites with small text
• Filling out forms without proper labels
• Navigating websites using only keyboard
• Viewing websites with poor color contrast
• Accessing websites that aren't accessible

⚠️ IMPORTANT DISCLAIMER

This extension helps improve web accessibility but does not guarantee full compliance with accessibility standards (WCAG, ADA, etc.). It's a tool to assist users, not a replacement for proper web design. See our disclaimer for full details.
```

## Manifest Permissions Justification

When submitting, you'll need to explain why you need each permission:

**activeTab**:
```
Required to access and modify the current webpage to apply accessibility improvements such as text size changes, contrast adjustments, and focus indicators.
```

**storage**:
```
Required to save user preferences (text size, contrast mode, panel position) locally on the user's device. No data is transmitted externally.
```

**scripting**:
```
Required to inject the accessibility control panel and apply accessibility enhancements to webpages.
```

**host_permissions (<all_urls>)**:
```
Required to work on all websites so users can improve accessibility on any site they visit. The extension does not collect or transmit any data from these sites.
```
