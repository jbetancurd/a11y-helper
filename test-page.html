🧪 Accessibility Extension Test Page

This page contains intentional accessibility issues to test your extension

📋 How to Use This Test Page

1. Make sure your Accessibility Helper extension is installed and active

2. Look for the floating panel in the bottom-right corner

3. Click the panel to see the accessibility score and detected issues

4. Try the "Fix Now" button to automatically fix issues

5. Test all the controls: text size, high contrast, keyboard navigation, read aloud

6. Use keyboard shortcut Alt+A to toggle the panel

✅ Extension Features to Test

  • Panel appears and is visible
  • Panel can be expanded and collapsed
  • Text size adjustment works (+ and - buttons)
  • High contrast mode toggles correctly
  • Keyboard navigation enhancement works
  • Read Aloud feature works
  • Accessibility score is calculated
  • Issues are detected and shown in tips
  • Auto-fix button works
  • Alt+A keyboard shortcut toggles panel
  • Settings can be saved

Text that is too small can be difficult to read.

This text is only 10 pixels tall, which is way too small for comfortable reading. Many users, especially older adults or those with visual impairments, will struggle to read this. The minimum recommended size is 16px for body text.
