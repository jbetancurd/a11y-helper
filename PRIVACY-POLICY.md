# Privacy Policy for Accessibility Helper Extension

**Last Updated**: January 2025

## Overview

Accessibility Helper is committed to protecting your privacy. This privacy policy explains how the extension handles data.

## Data Collection

**We DO NOT collect any data.**

Specifically, we do not collect, store, transmit, or share:
- Personal information
- Browsing history
- Website content
- User preferences (except locally)
- Usage statistics
- Analytics data
- Any other user data

## Local Storage Only

The extension stores settings locally on your device using Chrome's storage API. This includes:
- Text size preference
- High contrast mode setting
- Keyboard navigation setting
- Panel position preference
- Panel visibility setting

**This data:**
- ✅ Stays on your device only
- ✅ Is never transmitted to any server
- ✅ Is never shared with anyone
- ✅ Can be deleted by uninstalling the extension

## No External Servers

This extension does not:
- ❌ Connect to any external servers
- ❌ Send data to any third parties
- ❌ Use analytics services
- ❌ Include tracking code
- ❌ Display advertisements
- ❌ Make network requests (except for text-to-speech which uses browser's built-in API)

## Permissions Explained

The extension requests these permissions:

### activeTab
- **Why**: To access and modify the current webpage
- **What it does**: Allows the extension to improve accessibility on the page you're viewing
- **What it doesn't do**: Does not access other tabs or your browsing history

### storage
- **Why**: To save your preferences
- **What it does**: Stores settings locally on your device
- **What it doesn't do**: Does not send data anywhere

### scripting
- **Why**: To inject the accessibility panel into webpages
- **What it does**: Adds the floating panel and applies accessibility improvements
- **What it doesn't do**: Does not track or monitor your activity

### host_permissions (all_urls)
- **Why**: To work on all websites
- **What it does**: Allows the extension to help improve accessibility on any website you visit
- **What it doesn't do**: Does not collect data from websites

## Third-Party Services

This extension does not use any third-party services, APIs, or libraries that collect data.

The only external functionality is:
- **Text-to-Speech**: Uses your browser's built-in speech synthesis API (no data sent externally)

## Children's Privacy

This extension does not knowingly collect any information from anyone, including children under 13.

## Changes to Websites

This extension modifies the appearance and behavior of websites you visit to improve accessibility. These modifications:
- Happen only in your browser
- Are temporary (reset when you reload the page)
- Are not visible to the website owner
- Do not send any data to the website

## Open Source

This extension is open source. You can review the code to verify:
- No data collection
- No tracking
- No external connections
- Complete transparency

## Your Rights

You have the right to:
- Use the extension without providing any personal information
- Delete all stored data by uninstalling the extension
- Review the source code
- Modify the extension for personal use

## Data Deletion

To delete all data stored by this extension:
1. Go to `chrome://extensions/`
2. Find "Accessibility Helper"
3. Click "Remove"
4. All locally stored settings will be deleted
